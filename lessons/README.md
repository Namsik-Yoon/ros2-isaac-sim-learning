# 실험 안내

숙련 개발자가 ROS 2와 Isaac Sim으로 실제 시스템을 만드는 실험 모음입니다. ROS 경험이 없는 경우에도 필요한 API와 로보틱스 의미를 작업 중 확인할 수 있게 구성합니다.

| 문서 | 용도 | 시작 조건 |
| --- | --- | --- |
| [000 환경 점검](000-environment.md) | 선택 참고: 실행 환경 진단·복구 | 저장소와 Docker 접근 |
| [001 ROS 통신](001-ros2-topics.md) | 선택 참고: ROS CLI·토픽 연결 진단 | ROS Docker 이미지 |
| [002 주행 제어와 실패 실험](002-first-motion.md) | 기본 경로: 목표 지점 추종, 명령 중단·시간 변화 관측 | Isaac Sim 장면·Bridge 실행 준비 |

002는 **설계와 실행 계획이며 장면·제어기 실구동은 아직 검증하지 않았습니다.** 000·001을 이수하거나 확인 질문에 답해야 시작할 수 있는 구조가 아닙니다. Isaac 설치 준비가 남아 있으면 환경과 연결 구성을 진행합니다.

실험마다 데이터 흐름과 성공 기준을 정하고, 구현 → 실행 → 로그·지표 관찰 → 실패 주입 → 수정으로 이어갑니다. 환경과 반복 작업은 에이전트가 준비하고 핵심 제어·실험은 직접 수정할 수 있게 합니다. 설명과 질문은 필요한 설계 판단에 맞춥니다.

공개 기록에는 버전, 실행 명령, 변경한 조건, 측정 결과, 실패와 수정, 재현 방법을 남깁니다. 개인 답변과 상세 환경 출력은 `.learning/`에 보관합니다. [실험 문서 양식](template.md)을 사용하고 실행 전 가설을 관측 결과처럼 기록하지 않습니다.
