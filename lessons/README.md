# 실습 안내

Python 프로젝트 경험이 있고 ROS 2와 Isaac Sim을 처음 배우는 사람을 위한 과정입니다. 하루 60분을 기본으로 하고, 시간이 남으면 조건을 바꿔 실험합니다.

| 순서 | 결과 | 시작 조건 |
| --- | --- | --- |
| [000 환경 이해와 점검](000-environment.md) | 호스트와 ROS 2 컨테이너를 구분하고 환경 기록 남기기 | 이 저장소와 Docker 접근 가능 |
| [001 노드와 토픽](001-ros2-topics.md) | 두 프로그램이 메시지를 주고받는 모습 관찰 | ROS 2 학습 이미지 준비 |
| [002 Isaac Sim에서 첫 이동](002-first-motion.md) | 가상 로봇의 전진·회전·정지를 눈으로 확인 | 지원 OS, Isaac Sim 설치, ROS 2 Bridge와 장면 준비 |

002는 **장면 설정과 실제 구동 검증이 남은 실습 초안**입니다. 000·001의 터미널 통신 성공만으로 Isaac Sim 설치나 주행 성공을 기록하지 않습니다. 환경 구축을 기다리는 동안에는 001에서 노드·토픽·메시지를 충분히 익힙니다.

## 공부하는 방법

1. 오늘 목표와 시작 조건을 확인합니다.
2. 결과를 먼저 예측하고, 사용자가 명령이나 핵심 코드를 직접 실행합니다.
3. 실제 관찰과 예상의 차이를 한 문장으로 설명합니다.
4. 튜터는 확인 질문을 하나씩 묻고 답을 기다립니다. 도움이 필요하면 `힌트만 줘`라고 요청합니다.
5. 실행 성공과 이해 확인을 따로 기록한 뒤 다음 단계로 갑니다.

환경 설치·진단은 튜터가 도울 수 있습니다. 코드 작성·실험·설명은 사용자의 학습 활동이며, 튜터의 대신 실행 결과로 완료 처리하지 않습니다. 완성 예제를 요청하면 제공할 수 있지만, 이후 조건 하나를 직접 바꾸어 확인합니다.

## 공통 기록

각 실습이 끝나면 공개 학습일지에 아래 내용을 남깁니다.

- 오늘 목표와 사용한 환경 버전
- 직접 실행하거나 바꾼 내용
- 예상과 실제 결과를 보여 주는 짧은 출력 또는 화면
- 실패 원인과 해결, 아직 남은 질문
- 다음에 할 한 가지

개인 답변과 상세 환경 출력은 `.learning/`에 보관합니다. 공개할 로그는 개인 경로·이름 등의 포함 여부를 직접 확인합니다. 새로운 실습을 만들 때는 [교재 양식](template.md)을 사용합니다.
