# 000 — 내 실습 환경 이해하기

목표는 ROS 2를 실행할 위치를 구분하고, 다시 시작할 수 있는 환경 기록을 남기는 것입니다. 예상 시간은 30~60분입니다. 이미지 다운로드 시간은 별도입니다.

## 선행 조건과 시작 상태

- 이 저장소가 준비되어 있고 호스트에서 Python 3와 Docker에 접근할 수 있어야 합니다.
- 호스트 터미널을 저장소 최상위 폴더에서 엽니다. 자신의 복제 경로에서 `README.md`와 `scripts/`가 보이는지 확인합니다.
- ROS 2 학습 이미지 준비 여부는 저장소의 환경 안내에서 확인합니다. 이 수업에서 운영체제 업그레이드나 Isaac Sim 설치까지 완료했다고 가정하지 않습니다.

**호스트**는 현재 PC의 운영체제입니다. **컨테이너**는 이 PC 위에서 준비된 ROS 2 환경을 실행하는 공간입니다. 컨테이너 안에 Ubuntu 24.04와 ROS 2 Jazzy가 있어도 호스트의 Ubuntu 버전은 바뀌지 않습니다. 이 구분은 Isaac Sim의 호스트 지원 조건을 확인할 때 필요합니다.

## 직접 실행

### 1. 호스트 환경 기록하기

호스트의 저장소 최상위 폴더에서 실행합니다.

```bash
python3 scripts/doctor.py
python3 scripts/doctor.py --json --output .learning/environment.json
```

첫 명령은 결과를 화면에 출력하고 두 번째 명령은 개인 파일로 저장합니다. 화면 출력에서 OS, GPU, 여유 저장 공간을 찾아 각각 한 줄로 적습니다. 오류나 경고가 있다면 해당 문구와 실행 위치를 기록합니다. 진단 결과가 저장되었다는 것과 모든 설치 조건이 충족되었다는 것은 서로 다릅니다.

### 2. ROS 2 셸 들어가기

```bash
bash scripts/ros-shell.sh
```

이미지가 없다는 메시지가 나오면 호스트에서 `bash scripts/build-ros.sh`로 준비한 후 셸을 다시 엽니다. 자세한 조건은 [환경 안내](../environments/README.md)를 확인합니다. 셸이 열리면 다음 세 명령을 **컨테이너 안에서** 실행합니다.

```bash
pwd
printenv ROS_DISTRO
ros2 --help
```

예상 관찰은 작업 경로 `/workspaces/ros2-learning`, 배포판 이름 `jazzy`, 그리고 ROS 2 명령 목록입니다. 작업 경로는 호스트 저장소가 컨테이너에 연결된 위치이므로, 이 경로 아래에 만든 파일은 호스트에서도 보일 수 있습니다.

### 3. 나왔다가 다시 들어가기

```bash
exit
```

호스트로 돌아온 뒤 `pwd`를 확인하고 `bash scripts/ros-shell.sh`로 다시 들어갑니다. 실행 중인 노드가 있을 때는 먼저 해당 터미널에서 `Ctrl+C`로 종료합니다.

## 성공 기준

- [ ] 사용자가 진단 명령을 실행하고 OS·GPU·여유 공간을 찾았다.
- [ ] 사용자가 컨테이너에서 `jazzy`와 ROS 2 도움말을 확인했다.
- [ ] 컨테이너 셸을 종료하고 다시 열 수 있다.
- [ ] 호스트 OS와 컨테이너의 ROS 2 환경을 자신의 말로 구분했다.

튜터가 환경을 대신 점검한 경우에는 “환경 점검 완료, 사용자 실습 미완료”로 기록합니다.

## 초기화와 흔한 오류

셸을 `exit`로 종료한 뒤 스크립트를 다시 실행하면 시작 위치로 돌아옵니다. 호스트에 저장한 파일은 남아 있으므로 저장소를 삭제할 필요가 없습니다.

| 증상 | 먼저 확인할 것 |
| --- | --- |
| `scripts/doctor.py`를 찾지 못함 | `pwd`가 저장소 최상위인지 확인 |
| Docker 연결·권한 오류 | 원문을 기록하고 튜터에게 전달; 임의로 시스템 권한을 바꾸지 않기 |
| 호스트에서 `ros2: command not found` | `bash scripts/ros-shell.sh`로 들어왔는지 확인 |
| 이미지가 없음 | 저장소 환경 안내에 따른 이미지 준비 상태 확인 |
| 저장 공간 부족 경고 | 설치를 이어가기 전에 필요한 공간과 사용할 디스크 확인 |
