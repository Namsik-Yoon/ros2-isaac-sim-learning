# NNN — 화면이나 출력에서 확인할 수 있는 목표

상태: 초안 / 명령 검증 / 시뮬레이터 검증 중 해당 상태를 적습니다. 사용자 학습 완료 여부는 개인 진도로 별도 기록합니다.

예상 시간: 기본 60분 + 선택 30분. 이번 수업에서 직접 만들거나 설명할 결과를 한 문장으로 적습니다.

## 선행 조건과 시작 상태

- 필요한 이전 실습과 환경 버전
- 터미널 실행 위치, 켜져 있어야 할 프로그램, 종료해야 할 프로그램
- 준비된 입력·장면·파일과 초기 상태
- 아직 검증하지 않은 부분

## 필요한 개념

이번 행동을 이해하는 데 필요한 개념만 설명합니다. 새로운 용어는 일상 언어로 풀어 쓰고, 데이터 흐름이 중요하면 짧은 그림을 추가합니다.

## 직접 실행

1. 실행 전 예상 한 문장
2. 사용자가 작성하거나 실행할 최소 단계
3. 관찰할 출력·화면·데이터
4. 조건 하나를 바꾸는 실험

명령은 호스트/컨테이너/시뮬레이터 중 실행 위치를 표시합니다. 핵심 코드는 미션 또는 빈칸으로 제공하고, 힌트부터 단계적으로 돕습니다. 완성 예제 요청은 수용하고 이후 응용을 직접 수행합니다.

## 예상 관찰과 성공 기준

- [ ] 사용자 실행 근거
- [ ] 예상과 실제의 비교
- [ ] 자신의 말로 설명한 근거

에이전트의 실행 성공으로 사용자 학습 완료를 체크하지 않습니다.

## 초기화와 흔한 오류

실행 중인 프로그램을 종료하고 시작 상태로 돌아가는 방법을 적습니다. 증상별로 관찰 → 가능한 원인 → 다음 확인 순서로 작성합니다.

## 이해 확인 — 한 질문씩

튜터가 실제로 물을 예측·설명·전이 질문 하나를 적습니다. 답을 기다린 후에 보충 설명이나 다음 질문을 합니다.

## 기록과 다음 행동

오늘의 목표 / 직접 바꾼 내용 / 예상과 실제 / 실패와 해결 / 남은 질문을 기록합니다. 다음에 할 행동 하나와 선행 조건을 적습니다.

## 출처와 검증

사용한 공식 문서, 문서 버전, 확인 날짜를 기록합니다. 실제 실행 환경과 결과를 문서 조사와 구분합니다.
