# Isaac Sim 장면

주행 장면의 설정·생성 스크립트와 재현 정보를 이 폴더에서 관리한다. 아직 장면을 설치하거나 실행 검증하지 않았다.

첫 목표는 공식 TurtleBot 예제를 지원 환경에서 열고 ROS 2로 전진·회전·정지를 확인하는 것이다. 실제 검증 후 정확한 자산 경로, ROS 그래프, 단위, 초기 위치, 카메라 위치, 재설정 방법을 기록한다.

큰 NVIDIA 원본 자산이나 설치 파일은 복사해 커밋하지 않는다. 출처·버전·다운로드 절차를 기록한다. 드론 장면은 PX4·Pegasus 호환성 검증 후 별도로 추가한다.
